# Labels

The cleaned benchmark uses **deterministic offline silver labels** generated by `bench/build_silver_labels.py`.

Why silver labels are used here:
- they are fully reproducible offline
- they avoid API dependence for Objective 1
- they let another researcher rerun the benchmark from the shipped corpus and query files

Important note:
- for publication-quality final reporting, replace or validate these silver labels with human judgments where possible
- the scoring script works with any CSV that follows the same schema and can therefore be rerun later with manually curated labels
